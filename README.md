## What is it?

This is a set of exercises aimed at exploring FPGA Prototyping basics and Verilog

## Hardware

I was using the Tang Nano 9K FPGA board powered by Gowin GW1NR-9 chip

## Software

The project uses a set of open-source tools for compiling, modeling, preparing, and flashing the hardware described in Verilog:

- [Apicula](https://github.com/YosysHQ/apicula) / Bitstream Format for Gowin FPGAs;
- [Yosys](https://github.com/YosysHQ/yosys) / RTL Synthesis;
- [NextPNR](https://github.com/YosysHQ/nextpnr) / Place & Route Tool Supporting Gowin LittleBee Chips;
- [OpenFPGALoader](https://github.com/trabucayre/openFPGALoader) / Bitstream Flashing Tool;
- [Verilator](https://github.com/verilator/verilator) / Hardware Simulation Tool (Technically a Converter from Verilog Description to C++ Cycle-Accurate Models)

Also, GTKWave was used for viewing waveforms generated by Verilator models
